📖 Architecture & Machine Learning Theory

1. Single Decision Tree vs. Random Forest Ensemble

A Decision Tree partitions feature space using axis-aligned orthogonal cuts to maximize Information Gain (Gini Impurity reduction or Entropy). While Decision Trees are highly interpretable and capture non-linear relationships without scaling, deep trees suffer from high variance and overfitting.

A Random Forest mitigates overfitting by combining hundreds of decorrelated Decision Trees via Bootstrap Aggregation (Bagging) and Random Subspace Method (feature bagging). By averaging individual tree variance, Random Forests reduce total generalization error without increasing bias.

2. Preprocessing & Feature Engineering

  • Numerical Features (Age, Income, Credit Score, Tenure, Balance, Usage, Support Tickets): Standardized using StandardScaler ($\mu=0, \sigma=1$).
  • Categorical Features (Contract Type, Payment Method, Device Category): Encoded using OneHotEncoder to eliminate arbitrary ordinal assumptions.

3. Automated Model Selection Rule

The champion model is selected dynamically based on out-of-sample holdout test performance on the primary metric (F1 Score). The champion model binary is exported as champion_model.joblib for zero-latency REST serving.
